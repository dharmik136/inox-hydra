# Bug register: quality cycle 2026-10

Companion to [QUALITY_CYCLE_2026-10_PRD.md](QUALITY_CYCLE_2026-10_PRD.md).
Every finding here was found by using the product in a sandbox; 148 of the 160
raw findings were reproduced, the rest traced to exact lines.

| Stage | Count |
|---|---|
| Raw findings from six audits | 160 |
| Duplicates folded into another finding | 18 |
| Accepted | 142 |
| Very high (S1) / high (S2) / medium (S3) | 26 / 50 / 66 |
| Targets | 30 / 50 / 70 |
| Fixed / partly fixed | 139 / 3 |
| Sent back by review, then fixed and verified | 19 |
| Further defects found while fixing | 16 (15 fixed or removed, 1 open) |

The targets set how deep each audit looked. Nothing was invented or inflated
to meet them: each auditor reported fewer S1s than asked rather than pad, and
triage re-rated a finding only with a stated reason, listed below.

Partly fixed, and what is left:
- AUDIENCE-10: Analytics marks rounded figures (1.2K) as approximate; Posts and
  Patterns still treat post counts read as 1.2K as exact, because the extension
  does not yet send each count's precision.
- AUDIENCE-26: new captures no longer store an unread reach as 0; days stored
  by older versions keep their 0 until a data migration clears them.
- UX-26: the media library's delete asks, reports failures and is visible
  without hovering, and no longer implies uploads attach to posts; attaching
  media to a post is a feature, not a fix.
